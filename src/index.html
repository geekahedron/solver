Suggested next guesses

From this position, every answer still in the list must be finishable in at most n further guesses, counting the guess being scored. Later guesses follow the active guess mode and hard-mode rules on every step, the same continuation rules as expected steps. n starts at 6 minus clues already entered (a Wordle budget) and updates as clues are added or undone, until you edit the number. Steps is the average number of guesses. Max steps is the worst-case number. Worst is only the largest group this one guess leaves. With the box checked, the current scoring mode — including fewest expected steps — ranks only the guesses that proved Max steps ≤ n. On a long list the Max steps search beams continuations and keeps a guess only when a line is proved; an unproved guess is never treated as guaranteed. A full English opening often returns nothing that way. Tree is the other view: pick one starting word, play out a strategy, and see which answers exceed n.

#OpenerBitsScan

Guess mode, hard mode, and the solution layer are the same settings as Analysis. Wordle hard reuses greens and yellows on every later guess in the tree.

Scan openers tries each starter in order and stops at the first played strategy with max depth ≤ n. A shortlist line that finishes within n counts; the stronger “guaranteed” label is not required. Order: the pack’s opener list when it has one (English Wordle and the live WordleBot pack: SLATE, TARPS, CRANE, CRAMP, TRACE, STARE, CRATE, RAISE, ALERT, LATER), skipping any that are not legal guesses in the loaded pack. A pack with no list is ranked by expected information in bits (top 10). When 16 or fewer answers remain, it continues with those answers, then other dictionary guesses, then answers already ruled out, up to 40 more. The scan uses this card’s hard mode, guess mode, solution layer, later-guess policy, budget n, and the clues already entered.

      Field reference
      
    Full notes: docs/pack-format.md. Paths below are the keys the checker reports when something is wrong.
    
      
    
        
    id, name
    
        
    Short id (letters, digits, _, -) and the name shown in the preset menu.
    
        
    alphabet
    
        
    A string of one character per token when delimiter is none ("abcdefghijklmnopqrstuvwxyz", or Dungleon’s "WAMKVBSsDTNOowtFZCcR"). Otherwise an array of tokens (["AS","10C"]). Empty means any token. Case is kept when caseInsensitive is false, so S and s are different entities.
    
        
    delimiter
    
        
    none (one code point per token), charset (split on spaces and commas), or fixed (split on delimiterValue, default -). Case folding happens before the split, and only when caseInsensitive is true.
    
        
    length
    
        
    On each variant (or once at the top level). An integer from 1 to 20. A word is a list of that many tokens.
    
        
    pools.theoretical
    
        
    guessList — theoretical solutions are the guess list plus the known answers that pass the rules (English). known — reserved; known rows are still marked theoretical today. alphabet — reserved; the engine does not expand alphabet^length. generated — a shipped rules script fills the pool. Only rules/dungleon.js does that here. A known answer that fails the generator stays on the known list.
    
        
    variants[].knownSolutions, guessList
    
        
    The answer list and the optional extra guess list. Each one may be an array of words, a file name that ships under src/packs/ (Try it can read those), or an http(s) URL of a plain text list, one word per line. Try it fetches that URL in this browser and stores the words here, so nothing is uploaded and the pack still opens if the URL is down later. JavaScript const arrays are not parsed. The WordleBot remote block is a host cache of those files and is rejected in this editor.
    
        
    clueShape, clueAlphabet, clueCaseSensitive
    
        
    perSlot is one mark per token. whole is one clue for the guess (parsed, not scored, until a script defines it). mixed is reserved. Each mark has id, value (0, 1, 2, …), label, and symbols the result box accepts. role is absent, present, or correct. solve: true is the all-green mark. paint is the tile color (b, y, g, yp, gp). clueCaseSensitive: true keeps y and Y as different marks.
    
        
    feedback, rules
    
        
    feedback is wordle (extra copies go gray), simple (any present token goes yellow), or custom. rules is builtin:wordle, builtin:simple, or script:rules/….js. A script must export validGuess, validSolution, and consistent. Try it will load a script only when it is a file that already ships here (rules/wordle.js, rules/dungleon.js). Pasted JavaScript is never run. feedback: "custom" needs that shipped script; the page then uses its marks for the remaining list and for Analysis.
    
        
    guessMode
    
        
    any — any tokens of the right length may be typed. Suggestions stay on the loaded lists. dictionary — validGuess (the lists). hard — the guess must fit every clue. answersOnly — only rows still in the active remaining layer. Wordle hard (reuse greens and yellows) is a separate, weaker switch on the Analysis card.
    
        
    openers
    
        
    Starter guesses, on the pack or on one variant. A variant array replaces the pack list. The Tree quick picks use that list, in order, after dropping words that are not legal guesses. Omit it and the page ranks a bounded set by expected information.
    
        
    tokenRenderer, clueRenderer
    
        
    Tile chrome: tiles/letters, tiles/cards, tiles/dungleon (letters without forced capitals). Clues: clues/wordle-gyb, clues/arrows-lr, clues/mastermind-pips. These pick the tile shape. Pictures come from appearance.
    
        
    appearance (alias images)
    
        
    Optional. Omit it and every token is drawn as its letter. sheet is a sprite sheet: url (http, https, or a relative path), cellWidth, cellHeight, columns, and optional rows, offsetX, offsetY, gapX, gapY. entities is keyed by the alphabet token, case-sensitive. Each entry may have label, title, image (its own picture), and sprite as { "index": 0 } or { "col": 0, "row": 0 }. keyboard.source and tiles.source are auto (image, then sprite, then the letter), image, or sprite. A picture that fails to load shows the letter. data: and javascript: URLs are ignored. The sprite editor on this tab writes this object.
    
        
    keyboard.rows
    
        
    Optional rows of alphabet tokens for the on-screen keyboard. Each string is inserted exactly, so "s" and "S" are different keys. A case-insensitive a–z alphabet with no keyboard uses QWERTY. Any other alphabet is wrapped in pack order. Backspace and Enter are added by the page.
