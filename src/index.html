From this position, every answer still in the list must be finishable in at most n further guesses, counting the guess being scored. Later guesses follow the active guess mode and hard-mode rules on every step, the same continuation rules as expected steps. n starts at 6 minus clues already entered (a Wordle budget) and updates as clues are added or undone, until you edit the number. Steps is the average number of guesses. Max steps is the worst-case number. Worst is only the largest group this one guess leaves. With the box checked, the current scoring mode — including fewest expected steps — ranks only the guesses that proved Max steps ≤ n. On a long list the Max steps search beams continuations and keeps a guess only when a line is proved; an unproved guess is never treated as guaranteed. A full English opening often returns nothing that way. Tree is the other view: pick one starting word, play out a strategy, and see which answers exceed n.

#OpenerBitsScan

Guess mode, hard mode, and the solution layer are the same settings as Analysis. Wordle hard reuses greens and yellows on every later guess in the tree.

Scan openers tries each starter in order and stops at the first played strategy with max depth ≤ n. A shortlist line that finishes within n counts; the stronger “guaranteed” label is not required. Order: the pack’s opener list when it has one (English Wordle and the live WordleBot pack: SLATE, TARPS, CRANE, CRAMP, TRACE, STARE, CRATE, RAISE, ALERT, LATER), skipping any that are not legal guesses in the loaded pack. A pack with no list is ranked by expected information in bits (top 10). When 16 or fewer answers remain, it continues with those answers, then other dictionary guesses, then answers already ruled out, up to 40 more. The scan uses this card’s hard mode, guess mode, solution layer, later-guess policy, budget n, and the clues already entered.
